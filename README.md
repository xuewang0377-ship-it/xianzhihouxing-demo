# 先知后行 · 买手经营决策 AI 产品（静态演示版）

> ⚠️ **本演示站全部数据均为虚拟合成**，用于产品功能演示，不含任何真实业务数据、真实账号或真实经营指标。AI 结论为预置示例文本。

## 这是什么

面向电商买手运营的决策工具，解决两类判断问题：

1. **商业价值诊断** —— 建联新账号时缺少参照系。将创作者按「垂类 × 粉丝段」切分为对照基准组，每项指标仅与同类同体量样本比较得出百分位；变现能力拆为商单 / 电商 / 内容三条路径分别评分。
2. **品类经营指南** —— 拓展陌生品类时认知不可复用。知识层沉淀品质分级与常见风险，数据层呈现价格带结构、爆品特征与预热节奏，AI 在两层之上提炼备货指南与创作指南。
3. **场次方案生成** —— 以客单反推价格带、以目标反推货型配比，输出结构化执行方案。
4. **实证案例** —— 将预测与实际成交逐条对账，偏差反哺下一版知识层。

## 演示版说明

| 项目 | 说明 |
|---|---|
| 数据 | 1,200 个虚拟买手、21 个品类、217 组对照基准，均按原数据结构合成，取值全部虚构 |
| 诊断计算 | **真实运行**：分位插值、加权评分、GMV 三档测算逻辑与原版一致 |
| AI 生成 | 静态站无后端，输出为预置示例文本（标注 `demo-preset`） |
| 已移除 | 工具集模块（含内部系统界面）、全部内部域名与系统代号 |

## 技术实现

原版为 FastAPI + 前端单页应用。演示版通过一层 fetch 垫片拦截 `api/*` 请求，改由本地虚拟数据包响应，前端业务代码未作修改；后端诊断计算逻辑已移植为前端 JS。

```
index.html      前端单页（原版结构）
demo-shim.js    接口垫片 + 诊断计算逻辑
demo-data.json  虚拟数据包
```
