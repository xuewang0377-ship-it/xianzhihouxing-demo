让品类拓新有指南

买手运营工作中发现的两个 case：一是判断一个新开买手适合走哪条路，二是帮一个成熟买手拓一个陌生品类。把这两件事变成可查、可比、可复用的依据。

两个 case，两条主线

都来自买手运营的真实工作场景
这两个 case 对应两条核心链路——判断一个人该怎么走（诊断 → 对标 → 方案），和 帮一个人走进新领域（品类认知 → 备货 → 执行）。后面的六个模块，都是围绕这两件事展开的。

① 新开买手刚建联

建联时最先要判断什么
「这个账号现在处在什么水平？」「适合走蒲公英还是电商？」「商业价值该怎么评估？」「和他同水平的人在做什么？」
这些判断以前靠经验，答不准也答不全。现在把三条经营路径（蒲公英 / 电商 / 内容）拆开， 每条都跟同垂类同粉段的全站水位对比，再按身份类型 / 主营品类 / 客单价档位找出真正同水平的标杆， 看他们最近卖什么、接什么单、做什么内容。

② 存量买手已在播

他和我共同面对什么
已经在播的买手要拓新品类——比如一直播黄金，现在要开沉香专场。 买手对新品类一无所知，我自己也不一定懂。而优质买手一旦出现选品失误，损失的不只是一场 GMV。
所以要有一份能从 0 到 1 建立品类认知的东西：什么是好货、怎么分等级、行话怎么说、雷在哪里， 再叠上站内真实数据——谁在做、卖什么价、爆品长什么样、预热怎么排，最后落成一份可执行的场次方案。

卡点
买手要拓一个陌生品类（eg.一直播黄金，现在要开沉香专场）。在接触跨品类、全新品类且没有前置专业知识铺垫的情况下，买手本人和运营需要做大量的准备工作，信息冗杂且耗时耗力，而优质买手一旦出现选品失误，损失的不只是一场 GMV。
做法
把品类认知拆成知识层 + 数据层：知识层沉淀什么是好货、怎么分等级、行话怎么说、雷在哪儿；数据层接站内真实场次——谁在做、卖什么价、爆品长什么样。AI 在两层之上做解读，而不是凭空编。
产出
21 个品类的可查手册。新人开一个没做过的专场，不再依赖口口相传的经验，把一次性的经验变成组织能力。在此基础上，再由 AI 基于站内大盘实际数据提炼出该品类的爆品公式（备什么货）与预热内容公式（发什么能拉到预约）。↓ AI 品类解读在本页最下方，选定品类后点击生成。

场次方案生成

买手 × 品类 × 目标 GMV → 七段式执行方案
卡点
诊断和指南都是「看」，真要落地还得有人把判断翻译成可执行的一场直播。以前写一份全案要半天，而且每个人写出来的质量参差不齐，货盘结构、预热节奏全靠个人习惯。
做法
把全案固化成七段式结构，用买手实际客单反推价格带、用目标 GMV 反推货型配比（引流 / 福利 / 利润 / 镇场），每一条建议都能追溯到具体数字。
产出
输入买手 + 品类 + 目标 GMV，几分钟拿到一份能直接发给买手的方案，把个人经验变成统一 SOP。
整合账号诊断 + 品类数据 + 对标，产出可直接执行的方案。方案结构固定为七段：目标测算 / 货盘结构 / 预热时间轴 / 预约笔记选题 / 直播当天节奏 / GMV 四来源拆解 / 关键成功要素与风险。结构不变，AI 只填内容。

复盘时我多留意的一个维度

常规复盘多止步于退款率，我尝试再多看一层

这场退款率 61.1% 偏高（GMV 1,580万 / 有效成交 613万）。常规复盘多关注退款率与销售额；我认为还应关注一个维度——商家的发货率与发货速度。

在标杆买手的大场中，发货速度直接影响粉丝口碑与复购，而这一变量在许多品类的复盘中容易被忽略。因此在后续选品中，我会将「发货能力」纳入商家筛选维度。一场大播真正的口碑，往往不在下播那一刻，而在货品送达粉丝手中那一刻。
